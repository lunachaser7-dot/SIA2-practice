# Church Finance System

A web-based system designed to manage and track church finances, including income, expenses, donations, and financial reports. Built with **HTML, CSS, JavaScript** for the frontend and **Node.js + MySQL** for the backend.

---

## 📂 Project Structure

---

## ✨ Core Features
✅ **Secure Login System** – Access only for authorized users  
✅ **Income Management** – Track offerings, tithes, donations, and other income sources  
✅ **Expense Management** – Record and categorize all church expenses  
✅ **Transaction History** – Full log of all financial movements  
✅ **Financial Reports** – Generate daily, weekly, and monthly summaries  
✅ **Data Analytics** – Visual charts for better financial overview  
✅ **Role-Based Access** – Admin and staff permissions  

---

## ⚙️ Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MySQL (phpMyAdmin)
- **Tools**: Git, GitHub, XAMPP/WAMP
